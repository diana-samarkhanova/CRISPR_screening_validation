# Public release checklist

- [ ] Confirm institutional and PI approval for unpublished screen use.
- [ ] Agree authorship and CRediT contributions before public disclosure.
- [ ] Assess patent or invention-disclosure obligations.
- [ ] Remove private screen counts and private annotation workbooks.
- [ ] Verify every dataset version and redistribution term.
- [ ] Record BioGRID ORCS release, retrieval date, screen IDs, and original
      publication links for every ORCS-derived record.
- [ ] Deduplicate article/preprint versions, repository mirrors, ORCS records,
      and alternative methods into source/raw-data families before splitting.
- [ ] Confirm that no unreported historical condition was filled from a library
      reference protocol such as Joung et al.
- [ ] Replace copied supplementary tables with accession-based manifests or
      independently curated factual records.
- [ ] Freeze data, code, environment, labels, and split assignments.
- [ ] Run all tests and reproduce every paper figure from a clean environment.
- [ ] Publish a tagged GitHub release.
- [ ] Archive that release in Zenodo and add the DOI to `CITATION.cff`.
- [ ] Publish a model card, data datasheet, changelog, and known limitations.
- [ ] Report failed and discordant validations, not only successful hits.
- [ ] Report results separately for screen-only, screen-plus-design, and
      context-aware feature profiles and their missingness strata.
